# Evaluacion2 - Software de Geolocalización y Rutas API

Este repositorio contiene la solución para la **Evaluación Parcial N° 2 (CUY6142)** de Telepresencia y Entornos Innovadores de Colaboración Humana.

Se desarrolló una aplicación interactiva en Python que consume la API REST de **GraphHopper** para el cálculo optimizado de rutas entre puntos geográficos.

- Interfaz e interacción totalmente traducidas al **español**.
- Salida de datos numéricos (distancias en km y millas) formateados con **2 decimales**.
- Opción de salida extendida permitiendo ingresar `"s"` o `"salir"`.
- Narrativa paso a paso de las instrucciones de navegación traducidas al español (`locale=es`).

- Python 3.8+
- Librería `requests` (`pip install requests`)
